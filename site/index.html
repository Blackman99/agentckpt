agentckpt snapshots your whole working tree, untracked files included, into a private store under .agentckpt/ while Codex, Claude Code, Gemini CLI, OpenCode or a Cursor agent works. When a turn goes wrong, restore any snapshot. Your branches, index and history are never touched.

Step 1 · init

  1. Fill the organizer

    $ agentckpt init

    Creates .agentckpt/ and appends .agentckpt/ to your .gitignore. That's the only file of yours it edits.

  2. Take one before the turn

    $ agentckpt snap -m "before agent"
b66469f  3 files  before agent

    Stages tracked and untracked files into the shadow index and commits them there.

  3. The agent acts up

    # edits a.txt, deletes untracked.md,
# creates new.py

    With the v0.2.0 hooks the agent takes its own dose before every prompt and edit; agentckpt watch also works.

  4. Give it the pill

    $ agentckpt restore b66469f
Skipped 1 conflict(s) … re-run with --force
  ! a.txt
Restored 2 file(s) from b66469f
$ agentckpt restore b66469f --force
Restored 3 file(s) from b66469f

    Bytes go straight back into the tree. new.py stays, since restore never deletes.

  5. Check for interactions

    $ git log --oneline
63fc0ae base

    No add, no commit, no checkout and no branch moves in your real repo.

Drug Facts

Uses

Temporarily relieves these symptoms of agentic coding:

  • /undo went missing in Codex; the issue asking for reliable rollback is still open (openai/codex#9203, 522 upvotes).
  • The agent deleted a file git never saw: git restore only knows tracked content (v2ex.com/t/1220282).
  • Stash and WIP commits leak agent noise into your index, reflog and branch (v2ex.com/t/1218209).

Directions

Adults and agents of all ages: Python 3.9+, git on PATH. Not on PyPI yet.

  1. Try ituvx --from git+https://github.com/Blackman99/agentckpt agentckpt demo
  2. Installpipx install https://github.com/Blackman99/agentckpt/releases/download/v0.2.0/agentckpt-0.2.0-py3-none-any.whl
  3. Takeagentckpt init && agentckpt snap -m "before agent"

The wheel comes from GitHub Releases v0.2.0.

Auto-refill new in v0.2.0

Let the agent take its own dose before each prompt, before each edit or shell command, and after each turn. Every config calls one command, which always exits 0 and never blocks a prompt or a tool call:

agentckpt hook --source claude    # Codex, Claude Code, Gemini CLI, OpenCode
agentckpt run -- aider            # anything else

Drop-in configs are in the hooks guide.

Warnings side effects in v0.2.0

  • Restore doesn't delete. Files the agent created after the snap stay. Use agentckpt diff <id> to see them.
  • Only what it saw. Gitignored files and files over 10 MiB (--max-bytes) aren't stored.
  • Hooks or polling. watch polls and can catch a half-written state; use the agent hooks (Codex, Claude Code, Gemini CLI, OpenCode) for clean per-turn snapshots.
  • An undo buffer, not a backup. The store lives in the project, so git clean -fdx removes it.

Do not operate heavy refactors without a snapshot.

Interactions

None with git. Every git command agentckpt runs looks like git --git-dir=.agentckpt/git --work-tree=.: a separate repo with its own index. Your HEAD, index, reflog and branches stay exactly as they were.
