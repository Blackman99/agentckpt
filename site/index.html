Small CLI. Clear rules.

  
Eight commands. Shadow git under .agentckpt/. Conflicts refused unless --force.

  

    
⌁
snap
Checkpoint the tree including untracked; skip huge files; never store .agentckpt.

    
↻
restore
Write snapshot files into the working tree. Real .git is never modified.

    
👁
watch
Stdlib polling auto-snap on change. No watchdog dependency.

    
☰
ls / diff
List snapshots, diff vs tree or between ids. --json for scripts.

  






  
Install in seconds

  
uvx --from git+https://github.com/Blackman99/agentckpt agentckpt demo
# or: pipx install git+https://github.com/Blackman99/agentckpt

agentckpt init
agentckpt snap -m "before agent"
agentckpt restore <id> --force
